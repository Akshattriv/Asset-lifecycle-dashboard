# Asset Lifecycle Dashboard

A full-stack dashboard for tracking the lifecycle of an enterprise device fleet,
built with **React (Vite + Recharts)** and a **FastAPI + pandas** backend.

IT teams that lease laptops and tablets on fixed terms need to know what is
about to expire, what is on order, and where stock is running short. This
project answers those questions from a single spreadsheet data source.

## Features

- **Lease lifecycle:** 10,000 devices on 4-year leases. Shows expired devices
  and those expiring in 30, 60 and 90 days, a 12-month expiry timeline, breakdowns
  by country layout (DE, FR, UK, IT, DK, HU, SE) and device type, and a
  searchable, filterable device table.
- **Replenishment tracking:** 453 HP devices on order, grouped by status
  (Ordered, In Transit, Delayed), device type and layout, with ETAs.
- **Stock aging:** HP vendor stock (5,684 devices) bucketed into older than
  30 days, 3 months, 1 year and 2 years, with age bands per device type.
- **Stock availability grid:** layout × device type heatmap showing
  In stock / Low stock / Out of stock, with an adjustable low-stock threshold
  and units already on order per cell.

## Tech stack

| Layer | Tools |
|---|---|
| Frontend | React 18, Vite, React Router, Recharts |
| Backend | FastAPI, pandas, openpyxl, Uvicorn |
| Data | Synthetic Excel dataset (generated by `scripts/generate_data.py`) |

## Architecture

The Excel workbook is loaded once into pandas. All business logic lives in
`backend/app/analytics.py` (framework-free, easy to unit-test), which FastAPI
exposes as REST endpoints (`/api/summary`, `/api/stock/grid`, ...). The React
app consumes them through a Vite dev proxy.
